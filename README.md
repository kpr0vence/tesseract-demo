# TesseractOCR for Reading a Receipt
This is the code for the TesseractOCR used by [Mr. Fridge](https://github.com/kpr0vence/MrFridge) to scan the text from a receipt. It makes sure to preprocess the image for better results. This code was developed in collaboration with my advisor, Dr. Sarah Van Wart.
